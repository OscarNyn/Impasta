# Impasta

A simple browser game project hosted in this repository.

## Files

- `index.html` — landing page for the website
- `Downloads/New folder (2)/Imposter.html` — the actual game

## Open locally

You can open the landing page directly in a browser:

- Double-click `index.html`, or
- Start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Publish as a website

1. Push this repo to GitHub.
2. Open your repository on GitHub.
3. Go to Settings → Pages.
4. Select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Save.

Your site will be available at:

```text
https://OscarNyn.github.io/Impasta/
```

## Notes

This project is a static front-end app, so GitHub Pages is a good fit.
